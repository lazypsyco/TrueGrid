# scanner-local-only: Unreal Editor instructions (rev 2)

The same change as `patch.json`, made by hand. Written against the **original**
TrueGrid 59f320b (1.3.4) asset. Use UE 5.6.1-CSS + SML 3.12.0 with your fork in `Mods/TrueGrid`.

**"Is this mine?"** means: **Get Player Controller** (the scanner's own variable) → **Is Valid**, and only
then **Player Controller** → **Is Local Controller**. Two Branches in a row, so nothing is ever called
on an empty reference. (Rev 1 used *Get Instigator Character*, which left single player without a
panel.)

## Walkthrough

**Open:** Content Browser → Settings → **Show Plugin Content** → TrueGrid Content → Equipment →
CircuitScanner → **FGNetworkScanner** → **Event Graph**.

**Building block used four times ("is this mine?"):**
- **Get Player Controller** → pure **Is Valid**: the green one returning a bool, *not* the ?IsValid
  macro. This goes into the first Branch's Condition.
- **Get Player Controller** → **Is Local Controller**. This goes into the second Branch's Condition.

### C1: start-up/equip: show only for the local player
1. **Ctrl+F** `Is Dedicated Server`. Use the **Branch** right after **Wait For Player State** / **Parent: Was
   Equipped**.
2. Feed that Branch's **Condition** from **Is Valid (Player Controller)**. This replaces the *Is
   Dedicated Server* wire.
3. **Alt+click** its **True** and **False** to break them.
4. Add a second **Branch**, Condition from **Is Local Controller (Player Controller)**:
   - first Branch **True** → second Branch;
   - second Branch **True** → **Add to Viewport** (Target **Debup**).

### C2: unequip: hide only for the local player
Same as C1 at the Branch after **Parent: Was Un Equipped**, ending in **Remove from Parent** (Target
**Debup**).

### C1+C2 clean-up
Delete:
- the two **Branch** nodes on **Is Server**;
- the four **Switch Has Authority** nodes;
- then the now-unconnected **Is Dedicated Server** and **Is Server**.

### C3: create the panel only for the local player
1. In the **Event BeginPlay** chain, break the wire **Set Circuit Scanner** → **Create Widget (Widget Debug
   Screen)**.
2. Insert the two Branches: **Set Circuit Scanner** → Branch (Is Valid) → **True** → Branch (Is Local
   Controller) → **True** → **Create Widget**.
3. Wire **both** Branches' **False** to the **Set Visibility** right after **Set Debup** (Target: the
   *Target* component).

### C4: per-frame panel work only where the panel exists
At **Event Tick**: break the wire to its first node (**Set Visibility**, Target *Screen Locator*). Insert
a **Branch** with Condition **Get Debup → Is Valid**; **True** → that Set Visibility. The panel now exists
only for the local player, so this is enough.

### C5: clean up when the scanner goes away
**Above the top of the graph** (clear of the comment boxes):
1. Add **Event End Play** → **Branch** (Condition **Get Debup → Is Valid**).
2. **True** → **Remove from Parent** (Target **Get Debup**) → **Set HUD Visibility** (Visible unticked).

**Compile** (no errors), **Save**. The changed file is
`Mods/TrueGrid/Content/Equipment/CircuitScanner/FGNetworkScanner.uasset`.

## Test after either route
**Single player first:**
- the panel shows when you equip;
- it hides when you unequip;
- it's gone after you die with it equipped.

**Then host + you:**
- each equips and unequips;
- both equipped at once;
- your readout updates;
- die, swap tool, or leave/rejoin while equipped;
- the host's log has no `Accessed None … Debup`.
